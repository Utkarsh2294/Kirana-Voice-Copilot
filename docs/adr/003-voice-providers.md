# ADR-003: Voice primary and fallbacks

Accepted as the Phase 6 implementation direction. Sarvam input/output will sit behind provider interfaces. Capability matrices must be verified against current vendor documentation then. Bhashini/AI4Bharat and browser speech are potential fallbacks, not guaranteed language coverage. Phase 2 only previews gesture states and read-aloud text. Optional mic-level visualization discards samples; it does not record or transcribe.
